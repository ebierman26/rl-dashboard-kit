For Rocket League on Windows · Free

Your stats, every match.

RL Dashboard records every Rocket League match you play. You get an overlay on top of the game (session record, streaks, MVPs, who you're playing) and a stats dashboard. Everything stays on your PC.

Download the installer

https://github.com/ebierman26/rl-dashboard-kit/releases/latest/download/RL-Dashboard-Setup.exe

Windows 10 or 11. Takes about two minutes. The link always gives you the newest version.

Install once

  1. Run the installer

    Double-click RL-Dashboard-Setup.exe in your Downloads.

    Blue "Windows protected your PC" box? That's normal for small free programs that aren't paid-signed. Click More info, then Run anyway.
    Windows Security says it found a threat? It's a false alarm (see below for what to do).

  2. Click through three pages

    • Welcome: click Next.
    • Where to install: the default is fine (or Browse to pick a folder).
    • Your Rocket League name: optional. Leave it empty and it's picked up in your first match. Then click Install.

  3. Click Yes when Windows asks

    Setup turns on Rocket League's built-in stats, which needs your permission once. If you don't have Python, it installs that too (a black window shows the progress).

  4. "You're all set!"

    It starts on its own whenever you log in to Windows, and you get an RL Dashboard icon on your desktop. If it says Almost done, it tells you exactly what to click.

  5. Where the overlay goes

    One screen? Set the game to Borderless, so the overlay can show on top of it:

    Settings›Video›Display Mode›Borderless

    Two screens? Keep Fullscreen and drag the overlay onto your other screen. Nothing to change in the game.

Playing every day

Just open Rocket League. Everything is already running.

Overlay

Drag it where you like. Right-click it for size, compact mode, lock and more. Ctrl+Shift+O shows or hides it, even in game.

Dashboard

Opens when the game starts, or click the RL Dashboard icon. Filter by mode and by today, this week or this month.

Tray icon

The RL icon by the clock (under the ^ arrow on Windows 11). Click it for the dashboard; right-click for everything else.

Updates automatic

Notification pops up by the clock→Click it→Read what's new→Click Yes

It restarts on the new version in a few seconds. Your name, settings and match history are kept, and nothing installs without your Yes. To check right away: right-click the tray icon, then Check for updates. Curious what changed? See the patch notes.

Good to know

I already have an older version.
Just run the installer. It finds your copy and updates it in the same folder, keeping your name, settings and match history.
Windows Security flagged the installer (e.g. "Trojan:Win32/Wacatac").
That's a false alarm. Windows sometimes guesses that a new program from a small developer is a threat, especially an installer few people have downloaded yet. The file has been reported to Microsoft as safe. To install anyway:
  1. Open Windows Security › Virus & threat protection › Protection history.
  2. Click the RL-Dashboard-Setup.exe entry, then Actions › Allow on device (or Restore).
  3. Download it again if it was deleted, and run it.
Rather not? Download the zip version instead: right-click it › Extract All, then double-click START HERE.
Will Rocket League think it's cheating?
No. It uses the game's official Stats API, which Psyonix provides for tools like this. It doesn't touch the game's files or memory, and the overlay is a separate window.
The overlay won't let me click it.
It's locked, so clicks go through to the game. Right-click the tray icon, then Unlock overlay.
A win or loss didn't count.
Right-click the overlay, then Fix record to add or remove one.
Change my name or turn off start-at-login?
Right-click the tray icon, then Settings.
Why does it look different around holidays?
The overlay and dashboard get a holiday look for Thanksgiving, Christmas, New Year's, Valentine's Day, St. Patrick's Day, the 4th of July and Halloween, then go back to normal. To turn it off, right-click the overlay and untick Holiday themes.
I play on more than one account.
Right-click the tray icon, then Settings. Type each account's name and press Enter to add it to the list, then click Save and start. Games on any of them count, and the dashboard gets an Account picker to see them together or one at a time.
How do I uninstall it?
Windows Settings › Apps › RL Dashboard › Uninstall. It asks whether to keep your match history.
