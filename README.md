# RL Dashboard

Live stats for every Rocket League match you play: an overlay on top of the game and a stats dashboard. Everything stays on your PC.

**📖 How to install and use it: https://ebierman26.github.io/rl-dashboard-kit/**

**Install:** download [RL-Dashboard-Setup.exe](https://github.com/ebierman26/rl-dashboard-kit/releases/latest/download/RL-Dashboard-Setup.exe) and run it.
Windows may say "Windows protected your PC": click More info > Run anyway.
